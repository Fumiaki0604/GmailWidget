# GmailWidget プロトタイプ仕様書

## 1. 概要

### 1.1 背景・目的
Gmailに営業・DMが多く重要メールが埋もれる問題を解決する。
デスクトップ上に常駐するウィジェットで、未読の重要メールをリアルタイムに提示し見落としを防ぐ。

### 1.2 ターゲットユーザー
- 主要ユーザー: Gmailをビジネス用途で使うWindowsユーザー
- 利用シーン: 業務中、PCを開いている間は常時起動

### 1.3 成功基準
- 重要メールがウィジェットに表示され、クリックでGmailに飛べること
- ルール設定（ホワイトリスト・キーワード）が操作できること
- AIスコアリングの擬似体験ができること

### 1.4 スコープ外
- 実際のGmail API通信
- 実際のClaude API通信
- システムトレイへの常駐（プロトではブラウザ表示）

---

## 2. デザインコンセプト

| 項目 | 内容 |
|-----|------|
| ターゲットの悩み | 大事なメールを見逃してしまう |
| 共感メッセージ | 「本当に大切なメールだけ、手元に届く」 |
| メタファー | デスク上の小さなインボックス |
| Before/After | メール洪水 → 厳選された重要メールのみ |
| カラー方針 | ダーク背景（作業中に目立ちすぎない）＋ アクセントはアンバー |
| 具体的約束 | 5分に1回自動チェック、スコア4以上のみ表示 |

---

## 3. データモデル

### 3.1 Email（メール）
| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | string | 一意識別子 |
| from | string | 送信者メールアドレス |
| fromName | string | 送信者名 |
| subject | string | 件名 |
| receivedAt | string | 受信日時表示用文字列（「10:32」「昨日 09:15」「3/1 14:00」） |
| receivedDate | string | 受信日（YYYY-MM-DD、ソート・比較用） |
| score | number | 重要度スコア（1〜5） |
| scoreReason | string | スコア理由 |
| isRead | boolean | 確認済みフラグ |

### 3.2 Settings（設定）
| フィールド | 型 | 説明 |
|-----------|-----|------|
| whitelist | string[] | ホワイトリスト（ドメインorメアド） |
| keywords | string[] | 重要キーワード |
| intervalMin | number | チェック間隔（分） |
| minScore | number | 表示する最低スコア |
| gmailUser | string | 認証済みGmailアドレス |

## 5. 画面仕様

### 5.1 ログイン画面（S01）

#### レイアウト
```
┌─────────────────────────┐
│  📧 Gmail重要メールウィジェット  │
│                         │
│  ┌───────────────────┐  │
│  │ Googleでサインイン  │  │
│  └───────────────────┘  │
│                         │
│  ※ 実際の認証は行いません  │
└─────────────────────────┘
```

#### 要素
| ID | 要素 | アクション |
|----|------|-----------|
| E01 | アカウント選択（モック） | `佐藤史渉 <fumiaki@gmail.com>` など固定2件から選択 |
| E02 | Googleでサインインボタン | ローディング500ms → 選択アカウントを `state.gmailUser` に設定 → S02へ遷移 |

#### 状態
- **初期**: アカウント選択 + ボタン表示
- **ローディング**: 「認証中...」スピナー表示（500ms）
- **完了**: S02へ自動遷移（ヘッダーに選択アカウントを表示）

## 6. 状態遷移

```
S01（ログイン）
  └─ Googleでサインインボタン押下
       └─ 認証中500ms
            └─ S02（メイン）
                 ├─ 設定ボタン → S04（設定）
                 │    └─ 保存 → S02
                 ├─ 更新ボタン → S05（AIスコアリング中・800ms）→ S02（更新済み）
                 └─ メールカード → S03（詳細）
                      ├─ 戻る → S02
                      ├─ Gmailで開く → 別タブ（S02維持）
                      └─ 確認済み → S02（該当メール消去）
```

### 異常時の動作
- `state.currentEmail` がnullのままS03が呼ばれた場合 → S02へ強制遷移
- 設定データ破損時 → デフォルト設定で上書き

### ボタン表示条件
- 更新ボタン: S05表示中は `display:none`
- 確認済みボタン: isRead=trueの場合は `display:none`

---

## 7. 技術仕様

- **実装**: 1ファイル完結HTML（index.html）、幅380px × 高さ最大600px固定
- **データ永続化**: localStorage（キー: `gmail_widget_v1`）
- **外部通信**: 一切なし（モック）
- **スタイル**: ダークテーマ（背景 `#1a1a2e`、アクセント `#f0a500`）
- **フォント**: システムフォント（日本語対応）
- **アニメーション**: CSS transition / setTimeout によるモック非同期
- **バグ防止**:
  - 全ボタンに `type="button"`
  - 画面切替は `display:none`/`display:block`
  - 遷移関数冒頭にnullチェック
